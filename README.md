# BiteSpeed – ML Data Collection App

## Overview
BiteSpeed is a lightweight, local food‑ordering application designed to capture **strictly formatted machine‑learning data** for a canteen management system.  When a user places an order (dine‑in or pre‑book), the app instantly records the transaction in `data1.csv`, ready for downstream forecasting models.

---

## Project Structure
```
/e2
├─ backend/          # Node.js + Express API (writes orders to data1.csv)
├─ frontend/         # React + Vite UI, styled with Tailwind CSS, wrapped with Capacitor for Android
├─ data.csv          # Raw menu / item data (reference only)
├─ data1.csv         # Master ML‑ready database (generated by the backend)
├─ xgb.py            # XGBoost model training script
├─ get_predictions.py# Helper script for model inference
└─ start.bat         # Convenience batch file to launch the backend & frontend
```

## Prerequisites
- **Node.js** (v18+ recommended) and **npm**
- **Python 3.9+** (for `xgb.py` and prediction scripts)
- **Android Studio** (optional, for building the mobile APK)
- **Git** (optional, for version control)

## Setup
### 1. Clone the Repository (if not already done)
```bash
git clone <repo_url>
cd e2
```

### 2. Backend (The Brain)
```bash
cd backend
npm install          # Install dependencies
node server.js        # Start the Express server on port 5000
```
The server will create `data1.csv` automatically if it does not exist.

### 3. Frontend (The Face)
```bash
cd ../frontend
npm install          # Install React/Vite dependencies
npm run dev           # Launch the development server (http://localhost:5173)
```
Open the URL in a browser, place an order, and verify that a new line appears in `data1.csv`.

---

## Running the Full Stack Together
1. **Start the backend** (keep the terminal open).  
2. **Start the frontend** in a separate terminal.  
3. Interact with the UI – each order is appended to `data1.csv` in real time.

---

## Android Build (Optional)
> **⚠️ Windows Firewall Notice** – The phone must be able to reach your laptop on port `5000`.
1. Open **Windows Defender Firewall with Advanced Security** → **Inbound Rules** → **New Rule…** → **Port** → **TCP** → set port `5000` → **Allow the connection** → finish naming the rule (e.g., *NodeJS API*).
2. Ensure `frontend/src/services/api.js` contains your laptop’s current IP address (run `ipconfig` to find the IPv4 address).
3. Build the Android bundle:
```bash
cd ../frontend
npm run build            # Production build
npx cap sync android      # Copy assets to Android project
```
4. Open `frontend/android` in **Android Studio** → **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
5. Install the generated `.apk` on your device.

## Model Training & Inference
- **Training**: Run `python xgb.py` to train the XGBoost demand‑forecasting model using `data1.csv`.
- **Prediction**: Use `python get_predictions.py` to generate forecasts from the trained model.
